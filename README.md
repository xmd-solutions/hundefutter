# Napfglück – Hundefutter-Portfolio

Verspielte One-Page-Website für eine (fiktive) Hundefutter-Marke mit Scroll-Animationen:
Futternapf, der sich beim Scrollen füllt, horizontales Produkt-Karussell, Kreis-Reveal,
Pfotenspur, Futterrechner und Hunde-Fotowand.

Reines HTML, CSS und JavaScript – kein Build-Schritt, keine Abhängigkeiten.

## Lokal ansehen

`index.html` im Browser öffnen.

## Auf GitHub Pages veröffentlichen

1. Neues Repository auf GitHub anlegen, z. B. `napfglueck`.
2. Alle Dateien aus diesem Ordner hochladen (inkl. Ordner `img/` und Datei `.nojekyll`).
3. Im Repository: **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main**, Ordner **/ (root)** → **Save**
4. Nach 1–2 Minuten ist die Seite erreichbar unter
   `https://<dein-benutzername>.github.io/napfglueck/`

## Struktur

```
index.html   Seite inkl. CSS und JavaScript
img/         Hundefotos (JPG, je ca. 900 px breit)
.nojekyll    sorgt dafür, dass GitHub Pages die Dateien unverändert ausliefert
```
